# Tata Online Retail Store Analysis

## Overview

A Power BI data analytics project analyzing online retail transactions to identify sales performance, customer purchasing 
patterns, product performance, and revenue trends.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel

## Analysis

- Revenue and sales performance
- Product performance
- Customer purchasing behavior
- Sales trends
- Geographic performance
- Order and transaction patterns

## Key Skills Demonstrated

Power BI | DAX | Power Query | Data Cleaning | Data Visualization | Business Analysis
