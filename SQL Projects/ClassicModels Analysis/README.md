# ClassicModels SQL Analysis

## Project Overview

This project demonstrates SQL querying and data analysis using the ClassicModels database, a relational database containing 
information about customers, employees, offices, products, orders, order details, payments, and product lines.
The project focuses on using SQL to extract, transform, analyze, and interpret business data to answer practical business 
questions.

## Tools & Technologies

* MySQL
* MySQL Workbench
* SQL
* Relational Database Analysis

## Key Areas of Analysis

* Customer and order analysis
* Product and product-line performance
* Sales and revenue analysis
* Employee and sales representative performance
* Customer payment analysis
* Order status and delivery analysis
* Business performance trends

## SQL Skills Demonstrated

* SELECT statements
* WHERE and filtering
* ORDER BY
* GROUP BY
* Aggregate functions
* INNER JOIN
* LEFT JOIN
* Subqueries
* Date functions
* Calculated fields
* Business-focused SQL queries

## Project Objective

The objective of this project is to demonstrate how SQL can be used to transform relational database records into meaningful 
business insights that can support decision-making.

## Project Files

The SQL query files in this folder contain the analysis performed on the ClassicModels database.
