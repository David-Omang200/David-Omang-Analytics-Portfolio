# E-commerce Analysis

## Overview

An Excel data analytics project analyzing e-commerce sales data to understand revenue performance, product performance, customer purchasing patterns, and overall sales trends.

## Tools Used

- Microsoft Excel
- PivotTables
- Excel Charts
- Data Cleaning
- Data Analysis

## Analysis

- Revenue and sales performance
- Product performance
- Customer purchasing behavior
- Sales trends
- Quantity and transaction analysis
- Payment method analysis
- Category performance

## Key Skills Demonstrated

Excel | Data Cleaning | PivotTables | Data Visualization | Data Analysis | Business Insights
